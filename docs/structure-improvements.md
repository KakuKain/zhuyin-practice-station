保留水彩風格、課文範圍、既有教材 identity、收藏與默寫草稿。逐項執行並留下驗證證據；不加入登入、雲端同步或新的語音服務。

- [x] 1. 更新發布與操作測試：12 張課程卡、標題填寫、整輪聽寫、辨音自動換題與多點觸控。
- [x] 2. 統一書寫底層：共用單點手勢與取樣／重繪排程，自由畫板保持格子與筆跡比例，保留舊畫作。
- [x] 3. 整理共用樣式與字體：集中尺寸／字體角色，清理同規則的重複覆寫，保留水彩素材。
- [x] 4. 整理語音清單與查詢快取：文字＋讀音身份、來源／長度／版本、避免每次點擊重開錄音資料庫。
- [x] 5. 拆分流程狀態：默寫、聽寫與導覽各自管理，保留 controller 作協調層。
- [x] 6. 功能分批載入：教材管理、錄音管理與畫板按需下載；文字／作答格不模糊，背景不阻塞。
- [x] 7. 完整裝置備份與文件：含教材、草稿、收藏、設定、畫作、錄音；先驗證再還原，保護既有資料。

- 與修改前線上 v77 比較，首頁首次 JS 合計由 605,428 bytes 降至 523,664 bytes；估計 gzip 合計由 189,934 降至 173,222 bytes（約減少 8.8%）。首屏 script 請求由 6 增為 27；不能據此宣稱實際載入時間相同比例改善。教材管理、錄音管理、畫板與備份 chunk 不在首頁下載。
- 發布使用同一 Site 來源與建置產物；成功狀態另由部署回應確認。
- 紅米平板＋一般電容筆仍需使用者實機驗證；模擬 pointer 不代表硬體防手掌誤觸。

## 2026-10-08 聽寫／默寫漏筆與字重

- 修正細長電容筆接觸被單軸面積判成手掌，以及中途接觸放大時整筆被刪除。新行為保留已接受筆跡、忽略可疑後續點，原觸控抬起才開始下一筆。
- capture 失敗仍能落筆，由視窗抬筆／取消收尾；同一觸控跑到另一語詞格時不寫入該格座標，第二觸控不能接續筆畫。

- 驗證：117 項單元測試、Lint、TypeScript、Prettier 與靜態建置通過；新增 7 個書寫案例 × 5 個瀏覽器專案共 35 項通過，原有 practice 流程 40 項也通過。包含零壓力、點筆、coalesced 曲線、疑似手掌、取消、capture 例外、跨字格、保存／復原／重新載入與比對畫面。
